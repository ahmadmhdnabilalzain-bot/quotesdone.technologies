# Website inspiration log

Owner-supplied references for the QuotesDone Technologies hub site. Newest first.
Owner bar: extremely advanced 3D + motion graphics, futuristic, big-tech, must NOT look AI-made.

## 1. 99designs "3D websites" gallery (shared 2026-11-26)
URL: https://99designs.com/inspiration/websites/3d (read 2026-11-26, ~38 entries)

**What it actually is:** a gallery of freelancer concept thumbnails (GIFs and stills), not live production sites. Many are Figma/Wix/Squarespace concepts; themes skew crypto, NFT, AI-startup and 3D studios. One entry is labelled as an early AI-generated design.

**Patterns worth keeping**
- A single hero 3D object that carries the brand (e.g. a Cinema4D cube with video on each face, finished in After Effects).
- Dark ground, one light source, restrained palette.
- Hover/scroll interactions prototyped before build (Figma prototypes).
- "Multi-disciplinary technology group" landing pages: one group, several divisions, which is our structure.

**Patterns to avoid (they read as generic / AI / crypto)**
- Floating glowing orbs, gradient blobs, neon wireframe globes, glassmorphism cards.
- Stock 3D illustration sets; template-builder layouts.

**Verdict:** useful for mood only. Not the quality bar. The real bar needs live, award-level sites; waiting for the owner's reference video.
