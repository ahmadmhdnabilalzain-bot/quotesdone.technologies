Generated from the confirmed logo by `brand/logo/source/export_social.py` (never edit the PNGs by hand; rerun the script).

## Profile pictures (`profile/`): the Q mark, centred inside the circle-crop safe zone
- Upload the **1080** file anywhere; platforms downscale. 400 and 800 are provided for X/LinkedIn (400) and YouTube (800).
- Colourways: **carbon** (default), **alloy** (light), **rhodamine** (accent, use sparingly, e.g. a campaign).
- Use the SAME colourway on every platform so the brand reads as one.
